## How to Use This File

Auto-loaded on every machine, so it holds only what is **universally true of this codebase
regardless of machine posture**, stated as rules. ⭐ **The incidents and "why" behind each rule live
in `.claude/decisions.md`**, reached by anchor breadcrumbs — read the entry before arguing with or
changing a rule.

**Machine posture lives in a profile** (`machines/dev.md` or `machines/analysis.md`), selected by one
import line in the gitignored `.claude/machine.local.md`. Profiles **only add**; a rule that must
differ by machine is not stated here.

⛔ **If no machine posture profile appeared in your context, stop and say so before doing any work** —
do not infer the posture from disk. The usual cause is a missing `.claude/machine.local.md` (fresh
clone), which fails silently. `python tools/board.py` also reports it.

⭐ **This file + your profile + `MEMORY.md` have a 75 KB budget** (`tools/kb_index.py --check` fails
past it): retire or move a rule to its module doc rather than add one here.
`decisions.md#auto-loaded-instruction-budget`

## Environment

- `python tools/x.py` / `php tools/x.php` from the project root.
- **Commit messages go in a file: `git commit -F <file> -- <paths>`.** Hook-enforced by
  `tools/hooks/git_commit_guard.php`. `decisions.md#git-commit-guard-hook`
- ⛔ **Never stage, commit or stash a path you did not write.** Several sessions share this checkout.

## Prod writes

- ⛔ **A script that writes to prod in bulk goes through `lib/WriteScopeGuard.php`** — it counts its
  own predicate and refuses on a mismatch. Hook-enforced by `tools/hooks/prod_write_guard.php`.
- **Always state which environment a number came from**, in the output.
